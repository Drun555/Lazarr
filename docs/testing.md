# Проверки реализации

## Автоматический прогон

Основной приёмочный прогон: `nix develop --command pytest -q`.

Проверены следующие группы:

- **Фундамент:** общая идентичность Media, отдельные требования задач, одна подтаска фильма, выбор серий, атомарность, добавление новых эпизодов сезона, последний администратор, права и настройки.
- **Matching:** частичное покрытие batch-раздачи, внешние дорожки по эпизодам, отсутствие субтитров, неизвестные аудиоязыки, область свидетельств, неверное разрешение, неоднозначные видео, абсолютная нумерация, диапазоны серий, несовпадающие ID, похожие названия и сиквелы, обязательная фраза и отсутствие улучшения при том же разрешении.
- **Плагины:** обновление при активном старом вызове, откат без сети, неправильная SHA-256, несовместимый SDK, неполный контракт, шифрование секретов и инвалидация cookies.
- **Провайдеры:** RSS Nyaa, страницы деталей, получение торрента, Windows-1251, пагинация Rutracker, истечение сессии, многошаговая CAPTCHA, HTTP 429 и разнесённые по HTML-узлам подписи дорожек.
- **Kinozal:** настраиваемое зеркало, CP1251 и UTF-8 DOM, незакрытые ячейки реальной выдачи, относительная пагинация, авторизация паролем/cookies, torrent и magnet fallback, дополнительная вкладка «Релиз», изоляция комментариев/похожих раздач, сезоны перед словом «сезон» и неполное покрытие серий. Живой анонимный поиск на `kinozal.me` проверен на двух страницах Paradise, описание и языки — на раздаче 2074972; приватное получение torrent требует пользовательской учётной записи.
- **Субтитры:** параметры поиска OpenSubtitles по TMDB ID эпизода, API key, скачивание внешнего файла, регистрация в библиотеке и выдача через Jellyfin.
- **API/WebUI:** вход, CSRF, права аккаунтов, создание задач через API, метаданные, скрытие секретов, шаблоны, статика и OpenAPI.
- **Worker:** группировка задач в общий торрент, повторные запуски, пауза одного потребителя, ratio, неподходящее фактическое аудио, улучшение с сохранением других потребителей, календарь, восстановление намерения загрузки и повторный выбор текущей версии.
- **Миграции:** поэтапный upgrade, сохранение исходных данных, соответствие актуальным моделям и downgrade/upgrade дополнительных этапов.

## Настоящий libtorrent и ffprobe

Два интеграционных теста используют только локальные peers и синтетические данные:

1. `test_local_swarm_selective_download_and_resume`: обратный порядок файлов, выбор видео и внешнего аудио, скачивание, сравнение хешей файлов, исключение ненужного файла и восстановление состояния/счётчиков из resume data.
2. `test_real_worker_swarm_and_ffprobe`: генерация двух коротких видео через ffmpeg с русской аудиодорожкой, поиск через тестовый ContentProvider, решение Worker, общий торрент, скачивание по loopback и фактическая проверка ffprobe. Обе подтаски завершаются, отсутствующие субтитры остаются отдельной потребностью.

Эти тесты не используют публичные трекеры и не скачивают сторонние фильмы. При отсутствии системных bindings/ffmpeg они явно пропускаются; в Nix-прогоне доступны обе зависимости.

## Проверка браузером

В изолированном каталоге `/tmp` проверены:

- Вход в тестовый аккаунт.
- Главная страница и настройки.
- Поиск через локальный HTTP-сервер, повторяющий ответы TMDB.
- Карточки результатов, выбор сериала, дополнительные поля.
- Создание сезона с тремя подтасками и выбранными языками субтитров.
- Раскрытие посерийного статуса.
- Узкая компоновка без горизонтального переполнения.

Тестовый пользователь и фиктивные метаданные не входят в рабочие данные проекта.

## Поставка

Дополнительные проверки: `ruff check`, `ruff format --check`, `node --check`, сборка wheel, проверка включения шаблонов/статики/миграций/плагинов, `pip check`, запуск закреплённого Nix devShell.

Dockerfile и Compose подготовлены, но Docker-образ в этой среде не собирался: Docker daemon отсутствует. Нативная интеграция libtorrent проверена через Nix. Для выпуска контейнера выполните `docker compose build` и сквозной smoke test из README на целевом Docker-хосте.

## Живые интеграции

12 сентября 2026 года после восстановления сетевого доступа проверен Nyaa: RSS-поиск вернул 75 кандидатов, HTML-описание разобрано, torrent metadata получены и прочитаны настоящим libtorrent (28 файлов). Скачивание медиаконтента не запускалось.

После подключения FlareSolverr 3.5.0 через Nix подтверждены вход в Rutracker, поиск и получение настоящего torrent-файла Re:Zero TV-2, часть 2 (тема 6088393). В структуре 102 файла: 12 видео, внешние озвучки, субтитры и шрифты. Медиа не скачивались. Cookies проверочного аккаунта хранятся зашифрованно вне исходников.

С пользовательским ключом подтверждены живые поиск TMDB, детали Re:Zero, структура эпизодов и альтернативная группа Seasons. Обложки проверены через серверный кэш и в браузере: все шесть карточек поиска загрузили изображения. Через WebUI создана задача на сезон 2 / серии 14–25 с 12 каноническими эпизодами TMDB 39–50.

Добавлены регрессионные тесты: структура файлов Re:Zero, явное преобразование номеров, общие эпизоды при разных схемах, запрет добавления следующего сезона при обновлении; создание первого аккаунта, CSRF и гонка bootstrap; кэш обложек; FlareSolverr, User-Agent/cookies, CP1251, сохранение query string и запрет подменять torrent bytes HTML-страницей. Браузером проверен путь первого запуска: создание аккаунта → вход → настройки; повторный bootstrap закрыт.

Один deprecation warning текущей версии Starlette относится к используемому тестовым клиентом HTTPX и не влияет на успешное выполнение тестов.

## Изменения расписания, удаления и языков (12 сентября 2026)

76 тестов проходят после реализации; добавлены ежедневный запуск и продолжение прерванного прохода, отсутствие повторного запуска после перезапуска, часовой пояс хоста/TZ, автоматическое обновление плагинов с локальным кэшем, DELETE с CSRF, сохранение общей загрузки, удаление последнего потребителя, защита путей и повторение очистки. Локальный swarm проверяет подтверждение удаления torrent handle и сохранение файлов движком перед явной очисткой ядром.

На сохранённой реальной раздаче Rutracker 6088393 повторно проверены все 12 эпизодов: JAP/японское встроенное аудио, три русские внешние дорожки на эпизод и русские/английские субтитры распознаются на этапе preflight. Проверка личности произведения остаётся UNKNOWN из-за отличающегося года сезона; ручные отклонения сохранены. Медиа не скачивалось. Предположение о языке из описания не заменяет неизвестный тег ffprobe. Браузером проверены названия языков, одна настройка времени, две группы провайдеров, Revert и диалог удаления со свитчем.

## Очередь и выбор языков

Добавлены проверки: немедленный поиск только новой задачи, добавление задачи во время активного поиска, сохранение запросов после перезапуска, объединение ручных запусков, соблюдение пауз и дат, ожидание провайдеров, авторизация/CSRF нового API и создание задачи без ожидания worker-lock. DOM-тесты (`npm run test:ui`) проверяют автокомплит по кодам и названиям, плашки, отсутствие дубликатов, клавиатуру, удаление выбранного языка, канонический payload, переход в «Библиотеки», индикатор поиска, прогресс загрузки медиа и ручной выбор раздачи для серии.

Добавлены регрессии для нескольких провайдеров: HTTP 504 у первого не мешает запросу второго, выключенный провайдер виден в отчёте, cooldown сохраняет первопричину и не изображается выполненным сетевым запросом. DOM-тест проверяет раздельные статусы Nyaa и Rutracker и заголовок неуспешного прохода.

`test_rate_limit.py` проверяет интервалы запросов виртуальными часами, конкурентные вызовы, отмену ожидания, общий лимит между сессиями плагина, `Retry-After`, растущую сохранённую паузу и объединение быстрых повторных запусков. Тесты плагинов/API/Worker проверяют сохранение порядка включённых провайдеров, валидацию списка и фактическую последовательность вызовов. DOM-тест проверяет стрелки перестановки, отправку нового порядка и недоступность перемещения за границы списка.

`test_selection.py` проверяет ранний отказ до вызовов inspect/resolve, сохранение кандидатов с неизвестными сведениями и частичным покрытием, альтернативную нумерацию, год сезона, отсутствие обязательной фразы, порядок проверки по разрешению, прекращение пагинации при cooldown и сохранение отложенного повтора только для нужного провайдера. Отдельный сценарий проверяет расширение запроса и журнал фактического текста. Офлайн-повтор сохранённых 33 раздач Re:Zero дал 26 отказов по заголовку; оставшиеся проверки включают совместное предварительное покрытие всех 25 эпизодов сезона двумя раздачами. Это проверка метаданных, не подтверждение ffprobe после загрузки.

Локальный swarm проверяет не только конечные файлы: при обратном порядке файлов торрента и ограниченной скорости E02 остаётся с нулевым прогрессом, пока E01 и её внешняя дорожка не готовы. Проверяется наблюдаемый прогресс E01, последующее автоматическое переключение на E02 и восстановление resume data. Unit-проверка отдельно запрещает переключение при завершённом видео, но незавершённом необходимом аудио.

Тесты библиотек покрывают классификацию японской анимации (включая фильмы) и японского игрового кино, общий Media двух пользователей, дедупликацию общей версии файла, календарь и альтернативную нумерацию, фактический last_search_at, различение предварительных и проверенных дорожек, доступ без сети, авторизацию API и отсутствие выбранных файлов. DOM-тест проверяет переход в библиотеку, выбор категории, открытие карточки и сведения о раздаче/дорожках.
