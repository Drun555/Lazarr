# Нагрузка после остановки Infuse — 27 сентября 2026

На Unraid с образом `sha-f7cfff7` Lazarr потреблял 86–140% CPU
(100% соответствует одному ядру). В коротких замерах iostat диск был занят
на 0,1–5,3%, доступно около 15,5 ГиБ RAM. Эти замеры не исключают всплески
нагрузки в другое время.

После остановки просмотра HTTP-соединений к процессу не осталось, но были
открыты 22 дескриптора первого фильма Kizumonogatari. Позиции проверенных
дескрипторов продолжали расти. За две секунды `rchar` вырос на 109 568 000
байт, при этом `read_bytes` не изменился: чтение шло из файлового кэша.
Профиль py-spy показывал активность AnyIO workers и HTTP middleware.

Воспроизведение на локальном Uvicorn: клиент запросил Range, прочитал
начало ответа и закрыл TCP-соединение. С прежним FileResponse и HTTP
middleware чтение между 150 и 400 мс после отключения выросло ещё на
297 926 656 байт. С исправлением счётчик оставался на 131 072 байтах:
дальнейшего чтения не было.

Исправление: отмена файлового ответа по `http.disconnect` с ожиданием
закрытия файла; security headers переведены на ASGI middleware без
промежуточного потока тела ответа. Проверены обычные и multipart Range,
HEAD, 416, завершение ответа и сохранение заголовков безопасности.
45 относящихся к изменению тестов прошли, Ruff и проверка формата прошли.
Локальный сервер перезапущен с исправлением, health отвечает успешно.

Активная раздача в диагностическом снимке была одна: 3 сида, 4 пира,
964 764 байт/с, без ошибки движка и без зависших приоритетов. Причинная
связь её низкой скорости с лишним чтением не доказана. Нужен повторный
замер после применения исправления. Продакшен не изменён.
