# Оценка раздач

Алгоритм находится в `lazarr-search-engine`, `selection.py`: `SCORE_WEIGHTS`,
`STAGE_THRESHOLDS`, `assess_candidate`. Lazarr исполняет этапы, хранит отчёты и
предоставляет ручной выбор. Новый отчёт требует SDK 1.7; старые движки продолжают
работать без баллов через совместимый интерфейс.

## Этапы

1. **Заголовок**, порог 20. Строится короткий список. Варианты запросов и страницы
   просматриваются до прежнего ограничения: до трёх страниц на вариант запроса.
2. **Описание**, порог 40. Изучаются до 12 лучших кандидатов каждого провайдера.
   Непрошедшим кандидатам не скачиваются torrent-метаданные. Названия и годы из
   описания читаются из подписанных полей, не из случайных упоминаний в сюжете.
3. **Файлы**, порог 100. Сопоставляются реальные файлы torrent-метаданных,
   проверяются эпизоды, качество и доступные сведения о дорожках. Фактическая
   проверка кодеков/дорожек после загрузки остаётся обязательной.

Оценка каждого этапа пересчитывается, а не добавляется к предыдущей.
Внутри каждой группы учитывается одно сильнейшее подтверждение. Повтор названия
в нескольких местах не увеличивает оценку. На третьем этапе заявленное наличие
серии заменяется результатом проверки файлов.

| Группа | Признак | Баллы |
| --- | --- | ---: |
| Идентичность | Совпали внешние ID | +120 |
| Идентичность | Собственное имя сезона и год | +90 |
| Идентичность | Имя сериала/алиас и подходящий год | +70 |
| Идентичность | Только имя | +20 |
| Сезон | Совпал номер сезона/показа | +30 |
| Сезон | Номер расходится | −10 |
| Эпизод, этапы 1–2 | Заголовок заявляет нужный эпизод | +10 |
| Эпизод, этапы 1–2 | Заголовок не заявляет нужный эпизод | −10 |
| Эпизод, этап 3 | Эпизод подтверждён файлами | +60 |
| Эпизод, этап 3 | Файлы явно содержат другие эпизоды | −20 |
| Эпизод, этап 3 | Нумерацию определить не удалось | 0 |

## Противоречия и выбор

Порог сам по себе не разрешает автоматическую загрузку: все обязательные
критерии должны быть подтверждены. Несовместимый тип содержимого, конфликт ID,
нарушение требований и явная чужая нумерация остаются блокирующими.
Ненумерованные `[TV]` / `[ТВ]` учитываются как `TV-1`. Совпадение номера показа
даёт +30 баллов, несовпадение −10 и само по себе не блокирует кандидата.
Одиночный `TV-N` может обозначать порядок показов: подтверждённые имя сезона
и год сильнее этой пометки. Также подходит точный алиас сериала с годом
запрошенного сезона, если известные сезоны не делают этот год неоднозначным. Явные сезоны в файлах и нумерация из метаданных
не переписываются эвристикой.

Среди полностью прошедших проверку кандидатов для каждой подтаски выбирается
максимальная итоговая оценка. При равенстве сравниваются разрешение, отсутствие
нужных субтитров, сиды, размер и стабильные идентификаторы. Поиск не завершается
на первом совпадении. Предел 12 подробных проверок действует отдельно для
каждого провайдера; результат является лучшим среди проверенного набора.

Если автоматического кандидата нет, пригодные для ручного выбора раздачи
сохраняются. Лучшая показывается как рекомендуемая, подтаска переходит в
`needs_selection`. Когда файлы не сопоставлены, интерфейс пишет «Требуется
сопоставление файлов». Отсутствие серии блокирует автоматический выбор,
но пользователь может явно указать видеофайл. До подтверждения никакая
загрузка не начинается. Отклонённые пользователем раздачи не рекомендуются.

Отчёт хранит баллы, источники, пороги и блокирующие причины отдельно по этапам;
карточка раздачи раскрывает их через «Оценка: … баллов · почему».

## Приоритет ранее выбранных тем

Перед общим поиском Lazarr обновляет темы, связанные с текущими файлами
выполненных подтасок той же задачи и сезона. Каждая тема проверяется один раз:
читаются актуальные заголовок, описание и torrent-метаданные. Старый состав
файлов не считается подтверждением наличия новой серии.

Все такие темы сравниваются по обычным баллам. Если они покрывают все искомые
серии и проходят обязательные критерии, общий поиск пропускается. Иначе
выполняется обычный поиск с сохранением уже проверенных вариантов и без
повторной проверки тех же тем. Ручной поиск альтернатив всегда продолжает
общий поиск. Отключённые провайдеры и паузы провайдеров учитываются; отклонённая
раздача не разрешает автоматический выбор. Планы ранее начатых загрузок
не меняются при обновлении темы.
