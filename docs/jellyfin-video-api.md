# Jellyfin: каталог и playback-ресурсы

Lazarr предоставляет совместимые клиентские маршруты для видео. Контракты сверяются с [официальной OpenAPI Jellyfin](https://api.jellyfin.org/openapi/jellyfin-openapi-stable.json). Это не отдельный Jellyfin Server и не обещание реализации всех параметров его API. Административные операции, изменение метаданных/библиотек, музыкальный каталог и SyncPlay не входят в этот слой.

`/System/Info/Public` и `/System/Info` возвращают `ProductName: Jellyfin Server` для обнаружения через Jellyfin SDK, в том числе в Wholphin. Отображаемое имя сервера (`ServerName`) остаётся `Lazarr`.

Ответ входа и чтение пользователя включают обязательные поля `UserDto`, `UserConfiguration`, `UserPolicy` и `SessionInfoDto` из Jellyfin Kotlin SDK 1.7.1. Контракт проверяет `tests/test_jellyfin_login_contract.py`, включая сохранение значений по умолчанию после частичного обновления настроек. Неподдерживаемые возможности (Live TV, SyncPlay, удалённое управление) обозначены как отключённые.

`tests/test_jellyfin_media_contract.py` проверяет обязательные поля каталога, медиадорожек, источников и глав в ответах каталога и PlaybackInfo. `IsInterlaced` и `IsHearingImpaired` учитывают метаданные ffprobe; `HasSegments` использует те же данные, что `/MediaSegments/{id}`.

## Каталог

- `/Items`, `/Users/{userId}/Items`: родитель, рекурсия, IDs, типы, поиск, исключения, watched/favorite/resume-фильтры, многопольная сортировка и пагинация.
- Дополнительные фильтры: жанры, студии, люди/роли, годы, возрастной рейтинг по точному значению, теги, статус сериала, видео/медиатип, контейнер, аудио/видеокодек, языки дорожек, наличие субтитров/описания/изображений/внешних IDs, размеры/HD/4K, диапазоны дат премьеры/добавления и численных рейтингов, missing/unaired, префиксы имени, соседние элементы.
- `sortBy` поддерживает несколько DTO-полей, а `sortOrder` — одно общее направление или направления по каждому полю. Есть специальные ключи `DatePlayed`, `PlayCount`, `IsFavorite`, `Runtime`, `SeriesSortName`, `DateLastContentAdded`, `Random`.
- `fields` ограничивает дополнительные поля DTO; `enableImages`, `imageTypeLimit`, `enableImageTypes`, `enableUserData` управляют размером ответа. Фильтрация и сортировка выполняются до проекции и пагинации.
- `/Search/Hints`, `/Items/Filters`, `/Items/Filters2`, `/Items/Counts`.
- `/Genres`, `/Persons`, `/Studios`, `/Years` и получение элемента по имени. Идентификаторы справочников стабильны; их можно использовать в фильтрах, запросах `/Items/{id}` и в качестве родителя.
- Read-only `BoxSet` формируются по коллекциям TMDB; содержимое доступно через `/Items?parentId=...`. Создания/редактирования коллекций через Jellyfin нет.
- `/Items/{id}/Ancestors`, `/Items/{id}/Similar`, алиасы для Movies/Shows, `/Items/Suggestions`, `/Movies/Recommendations`.

Similar ранжирует локальные произведения по пересечению жанров и людей. Recommendations использует просмотренные/избранные фильмы пользователя. Это локальная рекомендация, а не облачный сервис рекомендаций Jellyfin.

TMDB-провайдер 1.0.6 сохраняет участников, студии, рейтинг, статус сериала, коллекцию и ссылки на трейлеры. Для существующей установки нужно включить новую встроенную версию провайдера; старые записи с отсутствующими полями обогащаются при доступном провайдере. Отключённый или недоступный TMDB не блокирует чтение сохранённого каталога. Неизвестные данные не заменяются вымышленными значениями.

## Современные клиентские функции

- `/Items/Latest` и legacy-алиас сортируют по добавлению, учитывают типы, Played, HidePlayedInLatest, проекцию; `groupItems=true` группирует серии по сериалу. `groupItems=false` возвращает отдельные видео.
- `/Shows/Upcoming` выдаёт эпизоды из уже сохранённого расписания, начиная с текущей даты UTC, включая ещё не скачанные. Это не глобальная подписка на расписание всех сезонов TMDB.
- `Chapters` берутся из ffprobe. `/Items/{id}/Images/Chapter/{index}` извлекает изображение главы. Старые probe-данные обновляются при запросе карточки/PlaybackInfo.
- `Trickplay` в DTO описывает миниатюры шириной 320 px, шагом 10 секунд и листами 5×5. `/Videos/{id}/Trickplay/320/tiles.m3u8` и `/{index}.jpg` генерируют ресурсы по запросу для завершённых проверенных файлов.
- `/MediaSegments/{id}` возвращает сегменты из явно названных глав: Intro/Opening/OP, Recap, Outro/Ending/ED/Credits, Commercial, Preview. Есть фильтр `includeSegmentTypes` и стабильные IDs. Неназванная глава не считается заставкой; автоматического анализа звука/изображения для поиска intro нет.
- `/Items/{id}/LocalTrailers`, `/SpecialFeatures`, `/Intros`, `/ThemeVideos`, `/ThemeMedia` возвращают реальные локальные видео. Трейлеры TMDB отдельно доступны в `RemoteTrailers`.
- Для обнаружения локальных дополнений используются только файлы известных раздач, с подтверждённым полным скачиванием, совпадающим размером и успешной проверкой ffprobe. Поддерживаются каталоги `trailers`, `extras`, `specials`, `behind the scenes`, `deleted scenes`, `featurettes`, `intros`, `backdrops`; также суффиксы `-trailer`, `-behindthescenes`, `-deleted`, `-featurette`, `-intro`, `-theme`.
- Обнаружение выполняется при чтении карточки или списка дополнений. Дополнения не подменяют основное видео, не смешиваются с альтернативными версиями и имеют отдельное состояние просмотра. Файлы за пределами корня раздачи не выдаются.
- `/Videos/{id}/AdditionalParts` читает уже сохранённые связи частей. Автоматическое распознавание/скачивание CD1/CD2 по-прежнему не реализовано.

## Субтитры и дополнительные ресурсы

- Выдача внешних и извлечение встроенных текстовых субтитров: `/Videos/{itemId}/{sourceId}/Subtitles/{index}/Stream.{format}` и вариант со `/{startPositionTicks}/`.
- Форматы SRT, WebVTT, ASS/SSA, преобразование FFmpeg. Учитываются `startPositionTicks`, `endPositionTicks`, `copyTimestamps`, `addVttTimeMap`. Реплики на границе сегмента сохраняются и обрезаются; внешние UTF-8/CP1251-файлы нормализуются.
- `/Videos/{itemId}/{sourceId}/Subtitles/{index}/subtitles.m3u8`: VOD WebVTT HLS с параметром `segmentLength`. Авторизация переносится в ссылки сегментов. Полный результат извлечения кэшируется один раз, затем используются фрагменты.
- PGS можно извлечь как SUP без преобразования в текст. OCR, прожиг bitmap-субтитров, извлечение VobSub и обрезка SUP по времени не реализованы: неподдерживаемые запросы возвращают 415. Прямое воспроизведение исходных встроенных дорожек остаётся доступным совместимому клиенту.
- `MediaAttachments` в MediaSource и `/Videos/{itemId}/{sourceId}/Attachments/{index}` извлекают вложения, включая шрифты ASS. Пользовательские имена вложений никогда не используются как пути записи.
- `/FallbackFont/Fonts` и `/FallbackFont/Fonts/{name}` читают TTF/OTF/WOFF/WOFF2 из `data/fonts`; symlink-файлы не выдаются. Шрифты не скачиваются автоматически.
- Подтверждённые внешние аудиодорожки пробируются при PlaybackInfo, доступны для выбора и смешиваются с видео в поток Matroska через stream copy. Видеокодек не меняется. Такой поток не поддерживает HTTP byte ranges: seek выполняется через `startTimeTicks`. Это не универсальный HLS/transcoding pipeline и не делает неподдерживаемый клиентом кодек воспроизводимым.
- Обычный прямой файловый поток сохраняет Range/HEAD. Для изображений доступны width/height/maxWidth/maxHeight, JPG/PNG/WebP и quality с ограничением размеров.

Кэш производных файлов расположен в `data/cache/jellyfin-resources`. Ключ включает путь, размер и mtime источника, параметры и версию обработки. Запись атомарная, одинаковые задания сериализуются, одновременно выполняется не более двух заданий генерации и двух remux-потоков. Старые файлы очищаются при генерации: возраст 30 дней, целевой объём 1 GiB (свежие файлы не удаляются из-под активных запросов). Исходные видео и субтитры не изменяются.

## Проверки и ограничения совместимости

`tests/test_jellyfin_catalog.py` проверяет фильтры, проекцию, справочники, пользовательскую изоляцию, Latest и рекомендации. `tests/test_jellyfin_resources.py` создаёт настоящий MKV и проверяет субтитры/HLS/таймкоды, кэш, главы/изображения, trickplay, вложения/шрифты, Upcoming, обнаружение дополнений, отдельное состояние просмотра и remux внешнего аудио.

Это покрытие выбранных видеосценариев, а не 100% всех комбинаций параметров Jellyfin. В частности, не реализованы региональные таблицы сравнения `minOfficialRating`/`maxOfficialRating`, фильтры дат изменения метаданных, полноценные правила collapseBoxSetItems, музыкальные фильтры и универсальная согласованность с каждым DeviceProfile. Административные операции, Metadata Manager, загрузка/редактирование субтитров и SyncPlay намеренно отсутствуют.
