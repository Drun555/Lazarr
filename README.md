# Lazarr

*Not Lazarus. Think "lazy". Laz-arr. Get it?*

---

## Описание

Lazarr - это замена *arr-стека для Jellyfin - по крайней мере той части, что отвечает за видео. Lazarr принимает в себя реквест - название, сезон (если это сериал или шоу), нужное качество, языковые дорожки и опциональный список ключевых слов (например, SDR). На выходе у вас готовая библиотека с всеми метаданными для Jellyfin / Plex - не нужно ничего дополнительно переименовывать или скрапить, Lazarr все сделает за вас. 

Что делает Lazarr?
- Ищет подходящие реквестам раздачи
- Скачивает в нужном порядке (приоритизация по сериям) в последовательном режиме
- Мэтчит и ищет новые серии у онгоингов, сверяясь с календарём выхода
- Сопоставляет видеофайлы, аудиодорожки и субтитры между собой в случае, если в раздаче они лежат раздельно.
- Предусмотрено большое количество разных вариаций именований серий и сезонов, в том числе для аниме. Никаких проблем с наименованиями вроде Ep02 не будет, в общем.
- Предоставляет интерфейс для редактирования метаданных медиа.
- Lazarr также умеет комбинировать медиа из разных источников: например, первые 8 серий будут взяты из одного источника, а остальные - из другого. Для этого также предоставляется удобный интерфейс.
- Возможность проксирования запросов через Trawl / FlareSolverr
- Для определения реальных языковых дорожек раздачи используется как чтение темы / описания раздачи, так и полноценный ffprobe видеофайлов.
- Опциональный Telegram-бот для реквестов вне домашней сети.

По-умолчанию Lazarr раздаёт скачанные раздачи до коэффициента 3, потом останавливается. Данное поведение задаётся в настройках.

## Файловая структура
При деплое вы указываете папку загрузок. Внутри неё создаётся три папки:
- /source - оригинальные скачанные файлы без изменений
- /user - упорядоченная библиотека для Jellyfin / Plex вместе со всеми NFO-метаданными и обложками. Все контентные файлы являются симлинками на /source.
- /offline - место для оффлайн-данных контент-источников. Например, .xz оффлайн-дамп Rutracker можно положить в /offline/rutracker/*

## Источники
- Rutracker (в том числе из оффлайн-базы от spidergun) <- на данный момент единственный рекомендуемый трекер.
- Nyaa <- практически не тестировался. Скорее всего уберу, т.к. поиск серий на нужном языке - это боль.
- Kinozal <- для фильмов и сериалов работает нормально. В отличии от Rutracker, библиотека скудненькая.

## Производительность?
Нормально крутится даже на Intel N100. Разумеется, похвастаться небольшим RAM-usage не может: все-таки тут есть bundled торрент-клиент, а они прожорливые.  

## Запуск

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) в режиме WSL2.
2. Сохраните [compose.yaml](compose.yaml) в отдельную папку и откройте в ней Терминал через ПКМ.
3. Выполните:

   ```powershell
   docker compose up -d
   ```

Откройте [localhost:8000](http://localhost:8000), создайте аккаунт и пройдите настройку. Не забудьте добавить в закладки. Следуйте инструкциям и будьте лапочкой.
