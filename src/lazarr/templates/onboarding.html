Подключите TMDB

Добавьте ключ для загрузки постеров, описаний и рейтингов.

Как получить API Key TMDB?
  1. Создайте аккаунт на themoviedb.org ↗ и подтвердите почту.
  2. Откройте Настройки → API ↗ и оформите заявку на ключ для своего приложения.
  3. Заполните сведения о приложении и примите условия TMDB.
  4. Скопируйте API Key (v3 auth) и вставьте его в поле выше.

Подключите Telegram

Создайте бота в @BotFather и добавьте его токен.

Как создать бота и установить аватарку?
  1. Откройте @BotFather ↗ и отправьте /newbot.
  2. Выберите имя и уникальный username, заканчивающийся на bot.
  3. Скачайте аватарку выше. В BotFather отправьте /setuserpic, выберите своего бота и загрузите изображение.
  4. Скопируйте выданный токен и вставьте его в поле выше.
